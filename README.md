# TROTUAR!

A small browser arcade game set on busy city streets.

Walk through the crowd, react to approaching couriers, earn coins, and progress through the streets of TROTUAR!

## Play

**[▶ Play TROTUAR! 0.3.1](https://liberum-dev.github.io/trotuar-web/)**

No installation is required. The game runs directly in a modern web browser.

## Current Version

**0.3.1**

## Platform

- Web browser
- Desktop controls
- Mobile and tablet support
